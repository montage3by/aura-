# AI + Kommo CRM: 3 фичи для AURA (04.11.2026)

Цель: CRM не просто хранит лиды, а сама подсказывает, что делать, и снимает ручную работу с Антона и сейла. Реализация: Claude (по расписанию или по событию) + Kommo API + Telegram-бот.

## Что важно знать про Kommo (ресерч)

- **API v4 + долгосрочный токен приватной интеграции** — читаем и пишем сделки, контакты, компании, задачи, примечания, события. Сообщения из WhatsApp целиком через обычный API не отдаются (нужен отдельный Chats API add-on, работает не со всеми каналами) — проверить на пробном периоде.
- **Вебхуки через API — только на тарифах Advanced и Enterprise** ([docs](https://developers.kommo.com/docs/webhooks-general)), до 100 вебхуков, события: новая сделка, смена этапа, задачи и т.д. Без вебхуков работают только сценарии «по расписанию».
  ⇒ Для фичи №3 нужен тариф **Advanced** (~$25/польз./мес, на 5 чел. ~$125/мес).
- **Встроенный Kommo AI Agent** уже умеет отвечать в WhatsApp/Instagram, заполнять карточку и двигать сделку ([обзор](https://www.kommo.com/support/crm/kommo-ai-agent/)). Не дублируем его: он для первой линии в чатах, Claude — для аналитики, обогащения данных и работы со стройками.
- Похожие решения на рынке (n8n + Telegram, CRMchat, Bitrix-дайджесты) подтверждают рабочую схему: **расписание → чтение CRM → правила «где застряло» → AI пишет выводы и следующий шаг → Telegram**.

## Фича 1. Утренний дайджест в Telegram + узкие места

**Что получает Антон в 8:30 (пн–пт):**
1. Задачи на сегодня и просроченные — по каждому человеку.
2. 🔴 Узкие места: сделки без следующей задачи; без контакта больше N дней (N своё для этапа); «висят» на этапе дольше нормы; КП отправлено, ответа нет 3+ дня.
3. 🟢 Что сдвинулось вчера: новые лиды, переходы по этапам, выигранные/проигранные.
4. Топ-3 действия на день с готовым текстом сообщения (например, напоминание по КП).
5. Раз в неделю (пятница) — сводка: воронка по этапам, конверсия, источники лидов (LinkedIn / сайт / стройки), что сработало.

**Как работает:** задача по расписанию (Claude в облаке, scheduled task) → Kommo API (сделки, задачи, события за сутки) → правила зависания считаются кодом, Claude пишет выводы и рекомендации → Telegram Bot API `sendMessage` в личку Антону и в чат команды.

**Нужно в Kommo:** у каждой сделки — ответственный и следующая задача; нормы по дням для каждого этапа; поля «Направление» (Крупный девелопер / MEP) и «Приоритет».
**Тариф:** работает и на Base (только чтение по расписанию).
**Ценность:** Антон за 2 минуты видит, где теряются деньги, без захода в CRM.

## Фича 2. «Фото баннера или голосовое → лид в CRM» (Telegram-бот)

Под реальный процесс Антона: он ездит по стройкам и фотографирует постеры, а мы вручную разбирали 45 фото.

**Как работает:**
1. Антон шлёт боту фото постера (или визитки, экрана телефона с контактом) и/или голосовое «был на NOBU, говорил с Ахмедом из GECO, просил КП до пятницы».
2. Claude распознаёт текст: объект, участок, разрешение, девелопер, консультанты, генподрядчик, **MEP-подрядчик**, телефоны, email.
3. Проверяет дубли в Kommo (компания/объект уже есть?) и создаёт или обновляет: сделку-объект, компании, контакты, примечание с фото, задачу «следующий шаг».
4. Сам ставит приоритет по цепочке Антона: MEP известен → «звонить сейчас»; ГП не выбран / «на нуле» → «ранний вход»; ГП есть, MEP нет → «искать MEP».
5. Если MEP-подрядчика нет на постере — ищет в интернете и помечает «найдено в интернете, проверить» или «ИИ не нашёл».
6. Отвечает в Telegram: «Создал лид NOBU, 3 компании, задача: позвонить в GECO по ELV. Подтвердить?» — без подтверждения ничего не пишет в CRM.

**Тариф:** любой (пишем через API).
**Ценность:** база строек пополняется прямо с объекта, без ручного разбора; ничего не теряется из блокнота.

## Фича 3. Автоквалификация и обогащение новых лидов + черновик первого ответа

**Как работает (вебхук «новая сделка» / «новый контакт»):**
1. Лид пришёл с сайта, WhatsApp или LinkedIn → Claude определяет: B2B или B2C, сегмент (девелопер, УК/HOA, RAKEZ, отель, вилла), категорию Hemaya (Basic / Advanced) и срочность.
2. Обогащает: сайт и профиль компании, роль человека, есть ли у компании стройки в RAK, кто подрядчики.
3. Заполняет поля в Kommo, ставит воронку/этап и ответственного (крупный девелопер → Антон, мелкий B2B/B2C → сейл).
4. Готовит черновик первого сообщения под сегмент (вилла — про бесплатный выезд; бизнес — про проверку на соответствие Hemaya) и ставит задачу «ответить за 15 минут».
5. Для B2C-чатов в WhatsApp можно использовать встроенный Kommo AI Agent, а Claude — для квалификации и B2B.

**Тариф:** Advanced (нужны вебхуки).
**Ценность:** время ответа минуты вместо часов, сейл сразу видит, кто перед ним и что сказать.

## Что нужно решить заранее

- **Согласие Антона** на передачу данных CRM в AI-инструмент (NDA, п. 3) — письменно.
- **Тариф Kommo:** Base хватит для фич 1–2, для фичи 3 нужен Advanced.
- **Telegram-бот:** создать через @BotFather на рабочий аккаунт; кто получает дайджест (Антон, Анастасия, сейл).
- **Где это работает:** задачи по расписанию в облаке Claude; токены Kommo и Telegram — в секретах окружения, не в чате.
- **Нормы зависания по этапам** (сколько дней — нормально) — согласовать с Антоном.
