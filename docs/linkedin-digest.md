3. Разделить аутрич на два трека: партнёры (интеграторы — уже есть) и конечные клиенты (девелоперы, FM, RAKEZ, отели — собрать базу ЛПР по `target-segments.docx`).
4. Вести воронку аутрича в CRM: запрос → принят → диалог → встреча → сделка; привязать к постам (24 — девелоперам, 17 — интеграторам).
